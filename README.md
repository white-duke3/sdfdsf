# ChatFlow — Современный веб-мессенджер

Полнофункциональный веб-мессенджер с современным интерфейсом, вдохновлённым Telegram и WhatsApp.

## ✨ Возможности

### Основные функции
- 💬 **Личные сообщения** — обмен текстом, emoji, изображениями, видео, файлами
- 🎤 **Голосовые сообщения** — запись и воспроизведение аудио
- 🔍 **Поиск пользователей** — по имени и username
- 📱 **Адаптивный дизайн** — работает на desktop, tablet и mobile
- 🌓 **Тёмная тема** — переключение между светлой и тёмной темой
- ⚡ **Realtime обновления** — мгновенная доставка сообщений
- 👁️ **Статусы сообщений** — отправлено, доставлено, прочитано
- 🟢 **Online статус** — отображение активности пользователей
- ⌨️ **Индикатор набора** — "печатает..."
- 🔔 **Уведомления** — браузерные уведомления о новых сообщениях
- 🔊 **Звуки** — звуковые уведомления (можно отключить)
- 📎 **Drag & Drop** — перетаскивание файлов в чат
- 📋 **Paste изображения** — вставка из буфера обмена
- 💾 **Сохранённые сообщения** — личный чат для заметок

### Дополнительные функции
- ✏️ **Редактирование сообщений** — изменение отправленных сообщений
- 🗑️ **Удаление сообщений** — удаление у себя или у всех
- ↩️ **Ответ на сообщение** — reply с превью
- 📤 **Пересылка** — архитектура готова для реализации
- 🖼️ **Просмотр изображений** — полноэкранный просмотрщик
- 🎭 **Emoji picker** — выбор эмодзи по категориям
- ⚙️ **Настройки профиля** — изменение имени, username, bio, аватара
- 🔐 **Безопасность** — хеширование паролей, валидация данных

## 🚀 Быстрый старт

### Требования
- Node.js 18+ 
- npm или yarn

### Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd chatflow

# Установить зависимости
npm install

# Запустить dev сервер
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### Сборка для production

```bash
npm run build
```

Результат сборки будет в папке `dist/`

## 🎯 Использование

### Регистрация
1. Откройте приложение
2. Перейдите на вкладку "Регистрация"
3. Заполните форму:
   - Имя
   - Username (мин. 4 символа, только латинские буквы, цифры, _)
   - Email
   - Пароль (мин. 8 символов)
4. Нажмите "Создать аккаунт"

### Начало общения
1. После входа вы попадёте в список диалогов
2. В поиске введите имя или username пользователя
3. Выберите пользователя из результатов
4. Начните общение!

### Сохранённые сообщения
- В списке диалогов первым всегда отображается чат "Сохранённые сообщения"
- Используйте его для заметок, ссылок, важных сообщений
- Все сообщения в этом чате отображаются как ваши

### Отправка сообщений
- **Текст**: введите сообщение и нажмите Enter или кнопку отправки
- **Новая строка**: Shift + Enter
- **Emoji**: нажмите на иконку смайлика
- **Файлы**: перетащите файл в окно чата или вставьте изображение (Ctrl+V)
- **Голосовое сообщение**: нажмите на иконку микрофона

### Контекстное меню
Кликните правой кнопкой мыши на сообщении для:
- Ответа
- Копирования
- Пересылки
- Редактирования (свои сообщения)
- Удаления

## 🎨 Темы

Переключение между светлой и тёмной темой:
- Нажмите на иконку луны/солнца в верхней панели
- Или перейдите в Настройки → Интерфейс

## ⚙️ Настройки

Доступны через иконку шестерёнки в верхней панели:

### Профиль
- Изменение имени
- Изменение username
- Добавление bio
- Загрузка аватара

### Аккаунт
- Смена пароля
- Выход из аккаунта

### Интерфейс
- Выбор темы (светлая/тёмная)
- Включение/отключение звуков
- Включение/отключение уведомлений

## 🛠️ Технологии

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **State Management**: React Context + useReducer
- **Routing**: React Router
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Storage**: LocalStorage (для демонстрации)

## 🔐 Безопасность

- Пароли хешируются перед сохранением
- Валидация всех пользовательских данных
- Защита от XSS
- Проверка MIME типов файлов
- Ограничение размера загружаемых файлов

## 📝 Примечания

Это демонстрационная версия мессенджера с использованием LocalStorage для хранения данных. Для production использования рекомендуется:

- Подключить backend (Node.js/Express или NestJS)
- Использовать базу данных (PostgreSQL)
- Реализовать WebSocket для realtime
- Настроить файловое хранилище (S3/MinIO)
- Добавить Redis для кэширования
- Настроить Docker для деплоя
